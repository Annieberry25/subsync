# SubHalt Design System

## Design Philosophy

SubHalt should feel like a premium SaaS product that users enjoy opening every day.

The experience should be:

- Modern
- Elegant
- Calm
- Premium
- Trustworthy
- Easy to use

Every design decision should improve clarity before adding decoration.

# Glassmorphism

Glass is part of the SubHalt identity.

Never remove it.

Every glass surface should include:

- Backdrop blur
- Soft transparency
- Rounded corners
- Layered shadows
- Subtle glow
- Depth

The interface should never feel flat.

---

# Typography

Typography should adapt to each environment.

Do not use the exact same text colors across every theme.

Each environment should have its own:

- Heading color
- Body color
- Muted color
- Accent color

Typography should always feel like it belongs in the environment.

---

# Design Principles

Before considering any screen complete, ask:

- Does this feel premium?
- Does the typography belong?
- Do the cards blend naturally?
- Is there enough depth?
- Does the spacing feel intentional?
- Would someone enjoy using this every day?

If the answer is "no" to any of these, refine the design before shipping.

Add a button below it that says 'Get Started' or 'Continue' so they can proceed to the dashboard. Do not touch anything else.)

Success Messages
Examples:
Nice one! You’re now tracking Netflix.
Great choice! Pausing Canva saves you ₦8,000 every month.
(Celebrate actions without overdoing it.)

 Renewal Reminders
Examples:
😳 Hey buddy! This is your final reminder before Netflix renews tomorrow. Come check it out.
📅 Heads up! Spotify renews in 3 days.
Clear first. Friendly second.

⏳ Trial Messages
Examples:
⏳ Your free trial ends in 3 days. Decide before you’re charged.
🎉 Welcome! Your free trial starts today.
Always explain what happens next.

🌚 Empty States
Instead of:
No renewals.
Use:
🌚 Fear not. Nothing renews today. Enjoy the peace of mind. 😌
Instead of:
No subscriptions.
Use something like:
📦 Your subscription shelf is empty. Add your first subscription to get started.

The goal is to make empty states feel inviting.

📈 Price Changes
Examples:
📈 Heads up! Spotify’s monthly price has changed since your last renewal.
Always explain what changed.

🌐 Error Messages
Instead of:
Request failed.
Use:
😕 We couldn’t complete that right now. Please check your connection and try again.
Instead of:
Unknown error.
Use:
Something unexpected happened. We’re on it—please try again in a moment.
Human, but not overly casual.

Writing Principles
Every message should answer one of these questions:
What happened?
What should I do?
Do I need to worry?
What changed?
Can I relax?
If a message doesn’t help the user, rewrite it.
