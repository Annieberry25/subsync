# SubSync Design System

## Design Philosophy

SubSync should feel like a premium SaaS product that users enjoy opening every day.

The experience should be:

- Modern
- Elegant
- Calm
- Premium
- Trustworthy
- Easy to use

Every design decision should improve clarity before adding decoration.

---

# Midnight 🌙

## Personality

Professional, modern, focused.

## Inspiration

- Linear
- Raycast
- Arc Browser
- Vercel

## Visual Style

- Pure black main application and sidebar background (`#000000`)
- Dark charcoal card surfaces with subtle dark green undertone (`#101613`)
- Elevated surfaces and modals (`#111916`)
- Subtle dark gray/green borders (`#1C2924`)
- Soft teal-green backdrop glow
- Layered depth and clean contrast

## Typography

- Headings / Primary Text: Off-white (`#F5F7F6`)
- Body / Secondary Text: Slate gray (`#94A3B8`)
- Muted: Dark slate gray (`#94A3B8`)

## Accent

Teal (`#14B8A6`) with dark text (`#091512`) on primary interactive elements.

## Feeling

Like working in a premium developer tool.

# Glassmorphism

Glass is part of the SubSync identity.

Never remove it.

Every glass surface should include:

- Backdrop blur
- Soft transparency
- Rounded corners
- Layered shadows
- Subtle glow
- Depth

The interface should never feel flat.

---

# Typography

Typography should adapt to each environment.

Do not use the exact same text colors across every theme.

Each environment should have its own:

- Heading color
- Body color
- Muted color
- Accent color

Typography should always feel like it belongs in the environment.

---

# Design Principles

Before considering any screen complete, ask:

- Does this feel premium?
- Does the typography belong?
- Do the cards blend naturally?
- Is there enough depth?
- Does the spacing feel intentional?
- Would someone enjoy using this every day?

If the answer is "no" to any of these, refine the design before shipping.
